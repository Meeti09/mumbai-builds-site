# Mumbai Builds

Landing site for **Mumbai Builds** — a Mumbai-wide student innovation platform.
Tagline: *Build What Matters*.

The visual design system, layout structure, spacing scale, typography hierarchy,
interactions and scroll choreography are modelled on
[buildandgrow.gdgcloudmumbai.com](https://buildandgrow.gdgcloudmumbai.com/) as a
reference. **No Build & Grow content, branding, logos, imagery, people, sponsors
or partners are reused** — every string lives in `src/content/site.ts` and every
image is original SVG art generated by `scripts/gen-assets.mjs`.

## Stack

| | |
|---|---|
| Framework | Next.js 16 (App Router, Turbopack) + React 19 + TypeScript |
| Styling | Tailwind CSS v4 |
| Scroll | [Lenis](https://github.com/darkroomengineering/lenis) smooth scroll on the GSAP ticker |
| Animation | GSAP + ScrollTrigger (reveals, parallax, timeline train), Framer Motion (FAQ accordion, hero terminal) |
| Type | Google Sans (via Google Fonts, incl. the Devanagari subset) |

## Getting started

```bash
npm install
npm run assets     # generate public/art/*.svg (also runs automatically on build)
npm run dev        # http://localhost:3000
```

## Editing content

Everything textual is in `src/content/site.ts`. The components are
presentational — change copy, dates, prize amounts, tracks, FAQs and contacts
there and nothing else needs touching.

The FAQ answers were drafted from the Mumbai Builds brief (eligibility, team
size, fees, rounds, tracks, prizes, what to bring, travel, finale selection). If
you have final approved FAQ copy, replace the `faqs` array.

## Assets

`scripts/gen-assets.mjs` writes 37 original SVGs into `public/art/`:

- `logo.svg`, `hero-mark.svg`, `initiative.svg` — wordmark and hero lockup
- `emblem-mumbai.svg`, `emblem-region.svg` — insight-panel emblems
- `landmark-mumbai.svg`, `landmark-region.svg` — overview skylines
- `train.svg` — the timeline train
- `track-*.svg` — one artwork per track
- `avatar-01..12.svg` — mentor / jury / organiser / team placeholders
- `gallery-01..12.svg` — marquee tiles
- `partner-slot.svg`, `community.svg`

Replace any file in `public/art/` with a real image (keeping the filename and
roughly the aspect ratio) and the layout holds.

## Visual-comparison tooling

Used to iterate the design against the reference; keep or delete as you like.

```bash
npm run shots          # full-page shots at 390 / 834 / 1440 into .ref/shots
npm run shots:ref      # same for the reference site
npm run sections       # per-section shots + heights, for block-by-block diffing
npm run interact       # drives FAQ / tabs / hovers / mobile menu, reports console errors
node scripts/cropsel.mjs <url> <label> "#timeline" 390   # one element at one width
```

`.ref/` holds downloaded reference material and screenshots and is gitignored.

## Accessibility & motion

`prefers-reduced-motion: reduce` disables Lenis, skips the hero typing
animation, freezes the marquee, and forces all GSAP reveal targets to their
final visible state, so no content is ever stuck at `opacity: 0`.
